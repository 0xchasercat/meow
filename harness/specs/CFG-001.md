## Motivation

`meow` collapses the per-tool config graveyard into **one** human-edited source (CANON §18, principle 11, ADR-8). The ecosystem (VS Code, WebStorm, CI, `tsc`/`tsgo`) hardcodes `tsconfig.json`, so deleting it breaks everything; ADR-8 resolves this with **shadow configs** — the human edits only `meow.config.ts`, and `meow` regenerates the legacy files as derived artifacts (§18.1, §24.5 residual).

CFG-001 stands up `crates/config` with: (1) the typed `defineMeow({...})` **shape** as a serde model, and (2) `tsconfig` shadow generation — the regenerated `.meow/tsconfig.json` the delegated typechecker (ADR-5) consumes, plus the committed one-line root `tsconfig.json` `extends` shim. It wires `meow sync` to regenerate (CANON §19 `meow sync`).

Spine: this is the `Wave 1 (P0 · Foundations)` backlog item `CFG-001` (PLAN.md). It serves **I-1** (the generated shadow tsconfig is the *single* config the shared check/lint/format/bundle pipeline and the delegated daemon read — no per-tool config files, CANON §18 / §19) and **I-9** (generated artifacts are derived from one source, never hand-maintained drift; generated files are clearly marked so they are never hand-edited).

## Acceptance criteria

New crate `crates/config` (added to the workspace `members` created by DIST-001). Errors are typed (`thiserror`), never stringly-typed; nothing on the `load` path may `panic!`/`unwrap()` on user input (CRAFT Part B). Concrete surface:

### 1 — `defineMeow` shape (`crates/config/src/schema.rs`)

```rust
use serde::{Deserialize, Serialize};

/// The typed shape of `meow.config.ts` (CANON §18). Mirrors the `defineMeow({...})`
/// object exactly; `runtime.engine` is deliberately absent (ADR-1 — V8 non-swappable).
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(deny_unknown_fields, rename_all = "camelCase")]
pub struct MeowConfig {
    #[serde(default)]
    pub mode: Mode,
    #[serde(default)]
    pub workspace: Workspace,
    #[serde(default)]
    pub runtime: Runtime,
    #[serde(default)]
    pub install: Install,
    #[serde(default)]
    pub lint: Lint,
    #[serde(default)]
    pub format: Format,
    #[serde(default)]
    pub types: Types,
    #[serde(default)]
    pub test: TestConfig,
    #[serde(default)]
    pub permissions: Permissions,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Default, Serialize, Deserialize)]
#[serde(rename_all = "kebab-case")]
pub enum Mode {
    #[default]
    StrictWeb,    // "strict-web"
    NodeCompat,   // "node-compat"
    Legacy,       // "legacy"
}

#[derive(Debug, Clone, PartialEq, Eq, Default, Serialize, Deserialize)]
#[serde(deny_unknown_fields, rename_all = "camelCase")]
pub struct Workspace {
    /// Glob roots, e.g. ["apps/*", "packages/*"] (CANON §13).
    #[serde(default)]
    pub packages: Vec<String>,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(deny_unknown_fields, rename_all = "camelCase")]
pub struct Runtime {
    /// How TS is handled for execution. Only "strip" is meaningful in P0 (ADR-5, I-3).
    #[serde(default)]
    pub typescript: TsHandling,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Default, Serialize, Deserialize)]
#[serde(rename_all = "kebab-case")]
pub enum TsHandling {
    #[default]
    Strip,
}

#[derive(Debug, Clone, PartialEq, Eq, Default, Serialize, Deserialize)]
#[serde(deny_unknown_fields, rename_all = "camelCase")]
pub struct Install {
    #[serde(default)]
    pub mode: InstallMode,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Default, Serialize, Deserialize)]
#[serde(rename_all = "kebab-case")]
pub enum InstallMode {
    #[default]
    Pnp,          // "pnp"
    Vfs,          // "vfs"
    Materialized, // "materialized"
    Vendor,       // "vendor"
}

#[derive(Debug, Clone, PartialEq, Eq, Default, Serialize, Deserialize)]
#[serde(deny_unknown_fields, rename_all = "camelCase")]
pub struct Lint {
    /// rule-id -> severity ("error" | "warn" | "off").
    #[serde(default)]
    pub rules: std::collections::BTreeMap<String, Severity>,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum Severity { Off, Warn, Error }

#[derive(Debug, Clone, PartialEq, Eq, Default, Serialize, Deserialize)]
#[serde(deny_unknown_fields, rename_all = "camelCase")]
pub struct Format {
    #[serde(default)]
    pub style: FormatStyle,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Default, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum FormatStyle { #[default] Meow }

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(deny_unknown_fields, rename_all = "camelCase")]
pub struct Types {
    #[serde(default = "default_true")]
    pub strict: bool,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(deny_unknown_fields, rename_all = "camelCase")]
pub struct TestConfig {
    #[serde(default = "default_true")]
    pub isolate: bool,
    #[serde(default)]
    pub clock: Clock,    // "deterministic" | "system"
    #[serde(default)]
    pub network: Network, // "fake" | "real"
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Default, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum Clock { #[default] Deterministic, System }

#[derive(Debug, Clone, Copy, PartialEq, Eq, Default, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum Network { #[default] Fake, Real }

/// Per-package capability grants (CANON §15). P0 carries only `default`;
/// the per-package grant map lands with the capability subsystem.
#[derive(Debug, Clone, PartialEq, Eq, Default, Serialize, Deserialize)]
#[serde(deny_unknown_fields, rename_all = "camelCase")]
pub struct Permissions {
    #[serde(default)]
    pub default: Vec<String>,
    #[serde(default)]
    pub packages: std::collections::BTreeMap<String, Vec<String>>,
}

fn default_true() -> bool { true }
```

- Every nested struct has a `Default` so an absent key takes the CANON §18 default (`mode: strict-web`, `install.mode: pnp`, `types.strict: true`, `test.isolate/clock=deterministic/network=fake`, `format.style: meow`).
- `deny_unknown_fields` on structs: an unknown key in config is a typed error pointing at the field (I-9 spirit — config is one closed schema), **not** a silent ignore.
- Maps use `BTreeMap` so serialization is deterministically key-sorted (feeds byte-stable regeneration).

### 2 — Loading (`crates/config/src/load.rs`)

```rust
use std::path::{Path, PathBuf};

#[derive(Debug, thiserror::Error)]
pub enum ConfigError {
    #[error("no meow config found under {0} (looked for meow.config.json / meow.config.ts)")]
    NotFound(PathBuf),
    #[error("config at {path} is invalid: {source}")]
    Parse { path: PathBuf, #[source] source: serde_json::Error },
    #[error("meow.config.ts evaluation requires the runtime (RT-001), not yet available; \
             provide meow.config.json for now")]
    TsNotSupported,
    #[error(transparent)]
    Io(#[from] std::io::Error),
}

impl MeowConfig {
    /// Resolve and parse the project config. HONEST BOUNDARY (see Operator notes):
    /// until RT-001 lands, only the JSON form is evaluable; a `meow.config.ts` with
    /// no JSON sibling yields `ConfigError::TsNotSupported` (NOT a fabricated success).
    pub fn load(root: &Path) -> Result<MeowConfig, ConfigError> { /* see sketch */ }
}
```

- Resolution order under `root`: `meow.config.json` → parse via `serde_json` into `MeowConfig`. If only `meow.config.ts` exists, return `TsNotSupported` (clear, fix-pointing). If neither, `NotFound`.
- Parse failures surface the serde error with the file path; no `unwrap` on user bytes.

### 3 — Shadow generation (`crates/config/src/shadow.rs`)

```rust
/// First line of every generated, gitignored artifact. tsconfig is JSONC, so the
/// `//` comment is valid and tsc/tsgo ignore it. The committed root shim is the one
/// exception — it stays pure one-line JSON (see `write_root_tsconfig_shim`).
pub const GENERATED_HEADER: &str = "// GENERATED — do not edit (run: meow sync)";

/// Exact, byte-stable content of the committed root `tsconfig.json` shim (ADR-8).
/// Pure JSON (no header) so every legacy tool reads it; trailing newline included.
pub const ROOT_TSCONFIG_SHIM: &str = "{ \"extends\": \"./.meow/tsconfig.json\" }\n";

/// Regenerate `.meow/tsconfig.json` from `cfg`. Creates `.meow/` if absent.
/// Content = GENERATED_HEADER line + deterministically-serialized compilerOptions
/// derived from `cfg` (see mapping). Overwrites any prior file (it is a derived
/// artifact). Byte-identical for identical `cfg` (idempotent / I-9).
pub fn generate_shadow_tsconfig(cfg: &MeowConfig, root: &Path) -> Result<(), ConfigError>;

/// Write the committed root `tsconfig.json` shim iff missing or non-identical.
/// Byte-stable: writing twice yields the same bytes and the second call is a no-op
/// on already-correct content.
pub fn write_root_tsconfig_shim(root: &Path) -> Result<(), ConfigError>;
```

**`defineMeow` → `.meow/tsconfig.json` mapping** (the only mapping P0 owns):

| config field | `compilerOptions` |
|---|---|
| `types.strict` | `"strict": <bool>` |
| `runtime.typescript: strip` (always, I-3) | `"verbatimModuleSyntax": true`, `"isolatedModules": true`, `"erasableSyntaxOnly": true`, `"noEmit": true` |
| (fixed P0 baseline) | `"module": "esnext"`, `"moduleResolution": "bundler"`, `"target": "esnext"`, `"allowImportingTsExtensions": true`, `"skipLibCheck": true` |

Plus top-level `"include": ["."]`. `workspace.packages` does **not** yet produce `paths`/`references` — the `paths` mapping into `.meow/deps/` is LSP-001's job (CANON §20.1, Q8); CFG-001 emits only `compilerOptions` + `include` so the file is correct-and-minimal, never a half-baked path map.

Determinism: build a `serde_json::Value` (or an ordered struct) with a fixed key order, serialize with `serde_json::to_string_pretty`, prepend `GENERATED_HEADER + "\n"`, end with a trailing newline. Same `cfg` ⇒ identical bytes.

### 4 — `meow sync` (fenced edit in `crates/cli`)

`meow sync` regenerates the shadows (CANON §19 / §18.1): `MeowConfig::load(root)` → `generate_shadow_tsconfig(&cfg, root)` → `write_root_tsconfig_shim(root)`; prints what it wrote. Added behind the `// === CFG-001 ===` fence in the CLI command dispatch created by DIST-001.

## Non-goals

- **Generated root `package.json` projection** — CFG-002 (Wave 2 / P1). CFG-001 touches `tsconfig` only.
- **TS-config evaluation via the runtime** — needs RT-001 to execute `meow.config.ts`; until then `load` reads JSON and returns a typed `TsNotSupported` for a TS-only project (see Operator notes / I-11).
- **LSP shadow `node_modules` symlink map + tsconfig `paths`** — LSP-001 (P2, CANON §20.1, Q8). No `paths` mapping is emitted here.
- **Capability enforcement / per-package grant validation** — the `permissions` shape is parsed and round-tripped, but no tier/grant logic (ADR-6) is implemented.
- **Lint/format rule execution** — `lint.rules`/`format.style` are parsed only; engines are other specs.
- **Staleness detection / `meow doctor`** — only generation + the `meow sync` trigger here (§24.5 residual is doctor's job later).

## Interface

- Crate `crates/config` exporting: `MeowConfig` (+ nested types), `Mode`, `InstallMode`, `Severity`, `MeowConfig::load`, `generate_shadow_tsconfig`, `write_root_tsconfig_shim`, `GENERATED_HEADER`, `ROOT_TSCONFIG_SHIM`, `ConfigError`.
- CLI: `meow sync` — regenerates `.meow/tsconfig.json` + root `tsconfig.json` shim.
- On-disk contract:
  - `./tsconfig.json` (committed) — exactly `{ "extends": "./.meow/tsconfig.json" }\n`.
  - `./.meow/tsconfig.json` (gitignored) — `// GENERATED …` header + `compilerOptions`/`include` derived from config.
  - `.meow/` already gitignored (no .gitignore edit needed; verify the entry exists).

## Implementation sketch

- `crates/config/Cargo.toml`: deps `serde` (derive), `serde_json`, `thiserror`. Add `crates/config` to workspace `members`.
- `schema.rs`: the serde structs above. `load.rs`: resolution + parse. `shadow.rs`: header consts + the two generators; deterministic serialization helper `fn render_tsconfig(cfg: &MeowConfig) -> String`.
- `generate_shadow_tsconfig`: `fs::create_dir_all(root.join(".meow"))`; write `root/.meow/tsconfig.json` = `render_tsconfig(cfg)`. `write_root_tsconfig_shim`: read-compare-then-write `root/tsconfig.json` against `ROOT_TSCONFIG_SHIM` (skip write when identical to keep mtime stable).
- `crates/cli` (shared file): inside the DIST-001 command match, add a fence:

  ```rust
  // === CFG-001 ===
  Command::Sync => {
      let root = std::env::current_dir()?;
      let cfg = meow_config::MeowConfig::load(&root)?;
      meow_config::generate_shadow_tsconfig(&cfg, &root)?;
      meow_config::write_root_tsconfig_shim(&root)?;
      println!("synced .meow/tsconfig.json and root tsconfig.json shim");
  }
  // === /CFG-001 ===
  ```

  Coordinate the `Command` enum variant `Sync` with DIST-001 (CLI skeleton owner) over IRC if the dispatch shape differs.

## Tests required

`crates/config/tests/` (integration, using a `tempdir` root):

- **shadow files generated with the header** (→ I-9 / `types-fresh` setup): after `generate_shadow_tsconfig`, `.meow/tsconfig.json` exists, its first line equals `GENERATED_HEADER`, and the remainder parses as JSON with `compilerOptions.strict` reflecting `types.strict`. Proves generated artifacts are marked, never hand-maintained.
- **root shim content exact** (→ I-1): after `write_root_tsconfig_shim`, `./tsconfig.json` bytes equal `ROOT_TSCONFIG_SHIM` exactly — the single `extends` indirection that makes one config the source the whole pipeline + delegated daemon read.
- **regeneration is idempotent / byte-stable** (→ I-9): calling each generator twice on the same `cfg` yields byte-identical files (capture bytes, regenerate, assert equal) — staleness/regen must converge.
- **load honesty** (→ I-11): a root with only `meow.config.ts` (no JSON) returns `ConfigError::TsNotSupported`, not a default config; a malformed `meow.config.json` returns `Parse` with the path; an unknown config key errors (`deny_unknown_fields`).
- **mapping fidelity**: `types.strict: false` ⇒ `"strict": false` in the shadow; erasable-only flags (`verbatimModuleSyntax`, `isolatedModules`, `erasableSyntaxOnly`, `noEmit`) always present (I-3 alignment).

GATES: `graph-integrity` (I-1 — one config feeds the shared pipeline; no second tsconfig authority), `types-fresh` (I-9 — generated artifact marked + regenerable to identical bytes), `honesty` (I-11 — the TS-eval boundary is reported, never faked).

## Rollout

- Additive: new crate + one fenced CLI command. No data migration. Flag-free.
- **Reversibility:** delete `crates/config`, remove it from workspace `members`, and revert the `// === CFG-001 ===` fence in `crates/cli`. Generated `.meow/tsconfig.json` is gitignored (vanishes with `.meow/`); the committed root `tsconfig.json` shim is the only tracked artifact — `git rm tsconfig.json` undoes it. No other subsystem depends on CFG-001 in P0.

## Operator notes

- **HONEST BOUNDARY (I-11):** evaluating a real `meow.config.ts` requires the runtime (RT-001) to execute TypeScript. CFG-001 does **not** evaluate TS; it loads a static `meow.config.json` (or a TS-only project errors with `TsNotSupported`). When RT-001 lands, the TS-evaluated path is wired into `MeowConfig::load` behind the same return type. No doc/CLI string in CFG-001 may claim TS-config evaluation works.
- **Assumption (default chosen, no fork baked silently):** the pre-runtime config source is `meow.config.json` parsed by serde. CANON specifies `meow.config.ts` as the *human* source but does not name the P0 pre-runtime fallback; JSON is the boring, reversible choice (the serde model is identical, so swapping the front-end to TS-eval is a one-function change). Flagged to Main for `decisions.json` consolidation — not written to `decisions.json` here.
- **GENERATED header is JSONC:** valid only because tsconfig accepts comments; the committed root shim deliberately omits the header to stay pure JSON for maximum legacy-tool compatibility (and so the "exact content" test holds).
- **`.meow/` gitignore:** assumed already present (per assignment + ADR-8); the implementer should assert the entry exists rather than re-adding it.
- **CLI coordination:** the `meow sync` variant must match the `Command` enum/dispatch shape DIST-001 defines — confirm over IRC before editing the shared CLI file.
