## Motivation

A pure-ESM project with no `node_modules` (I-5) keeps its entire dependency reality in one file: `meow.lock.jsonl` (PKG-001). When a developer sees an unexpected package in that tree, the only honest answer to *"why is this here?"* is the path(s) from what the project **declared** down to the package — and that path is exactly the lockfile edge set. `why-dep` reads it back: each `LockEntry.dependencies` is `dep-name → exact version` (PKG-001 §A2), i.e. one directed edge per pair; the project's direct dependencies are the roots.

This is the first **OBS** subsystem deliverable and the smallest observability command (CANON §17: *"`why-dep <pkg>` — which workspace introduced it, which transitive path requires it, its version/hash …"*; CANON §6.2 / Article 9: *"Observability is built in, not an aftermarket plugin ecosystem"*). It is deliberately tiny, fully local, fully deterministic, and **network-free** — it computes over an already-resolved lockfile, never fetching or resolving.

Traceability:
- `plan_ref` → PLAN.md *Build sequence · P2 Packages & Resolution* + backlog *P2 `OBS-001` why-dep* + CANON §17 / §31 Phase-2 deliverables (`meow why-dep`) and the Days-61–90 milestone ("early `meow why-dep`").
- `constitution_ref` → **I-7** [`lockfile-integrity`] (the lockfile *is* the edge set; it is read through PKG-001's strict, integrity-checked reader and never re-resolved), **I-1** [`graph-integrity`] (`why-dep` consumes the *same* `meow.lock.jsonl` graph the one resolver loads from — so its answer matches what actually executes; it builds **no** second resolver), **I-11** [`honesty`] (an honest "not found" when the name is absent; it reports only what the lockfile proves — version + integrity hash — and explicitly does **not** claim capabilities/cost, which are P6).

## Acceptance criteria

Concrete, checkable Rust. The deliverable is in two layers:

1. a **pure, root-source-agnostic path-finder library** `meow-obs` (new crate) that reads only a parsed `&Lockfile` + a provided root set — depends on **PKG-001 alone**, never panics, never does I/O, and is deterministic; and
2. the **`meow why-dep` CLI** that obtains the roots from the project's declared dependencies and renders the report.

Every reachable failure is a typed error or a structured negative result — no `unwrap`/`panic!` on any input (CRAFT Part B): a malformed lockfile, an empty lockfile, a dangling edge, a cycle, or an absent name each produce a defined outcome, never a crash.

### A1 — Graph model + report types (`crates/obs/src/lib.rs`)

```rust
use std::collections::BTreeMap;
use meow_pkg::{ContentHash, Lockfile, PackageName, Version};

/// A resolved node identity in the dependency graph: an exact `(name, version)`.
/// Multi-version is inherent — `lodash@3.10.1` and `lodash@4.17.21` are two distinct
/// nodes (mirrors LOAD-003: the lockfile keys by `(name, version)`).
#[derive(Clone, PartialEq, Eq, PartialOrd, Ord, Debug, serde::Serialize)]
pub struct DepNode {
    pub name: PackageName,
    pub version: Version,
}

/// One dependency chain. `nodes[0]` is a project **direct dependency** (a root);
/// `nodes[last]` is the target node; consecutive nodes are a lockfile edge
/// (`nodes[i]`'s `LockEntry.dependencies` contains `nodes[i+1]`). Always a SIMPLE
/// path — no node repeats — so cycles cannot make it infinite.
#[derive(Clone, PartialEq, Eq, Debug, serde::Serialize)]
pub struct DepPath {
    pub nodes: Vec<DepNode>,
}

/// All the ways ONE concrete target version is reached.
#[derive(Clone, Debug, serde::Serialize)]
pub struct TargetVersion {
    pub node: DepNode,
    /// Integrity (SRI) from the matching `LockEntry`. `None` ⇒ the name@version is
    /// *referenced* by some edge but has no entry of its own (an incomplete lockfile
    /// — surfaced honestly, never silently dropped, I-11).
    pub integrity: Option<ContentHash>,
    /// `true` ⇒ this exact version is itself a project direct dependency (the chain
    /// to it is the single node `[node]`).
    pub direct: bool,
    /// Canonical-ordered, de-duplicated chains. In `PathMode::Shortest` this holds at
    /// most one (a shortest representative); in `PathMode::All` it holds every simple
    /// path up to `limit`.
    pub paths: Vec<DepPath>,
    /// `true` ⇒ `PathMode::All` enumeration hit `limit` and stopped (honest
    /// truncation — the printed paths are a deterministic prefix, not "all of them").
    pub truncated: bool,
}

/// The full answer for `why-dep <name>`.
#[derive(Clone, Debug, serde::Serialize)]
pub struct WhyDep {
    pub target: PackageName,
    /// `true` ⇒ `target` appears anywhere in the tree (as an entry, as an edge
    /// target, or as a declared+pinned root). `false` ⇒ the honest "not found".
    pub found: bool,
    /// One per matching version, ascending by `version`; empty when `!found`.
    pub versions: Vec<TargetVersion>,
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum PathMode {
    /// Every simple path from a root to the target (the default — a package's full
    /// "why" includes every owner that pulls it in).
    All,
    /// One shortest path per target version (BFS; ties broken canonically).
    Shortest,
}

/// Default cap on enumerated simple paths *per target version* (`PathMode::All`).
/// Simple-path enumeration is worst-case exponential; the cap keeps `why-dep`
/// total and fast and forces an honest "truncated" note rather than a hang (I-11).
pub const DEFAULT_PATH_LIMIT: usize = 256;

/// THE function. Pure, total, deterministic, no I/O, no network. Reads only the
/// lockfile edge set (`LockEntry.dependencies`) and the provided `roots`.
///
/// `roots`: the project's direct dependencies pinned to exact versions (name →
/// version). Supplied by the caller — the library does not know or care where they
/// came from (the CLI sources them from `MeowConfig`; tests pass them directly).
pub fn why_dep(
    lockfile: &Lockfile,
    roots: &BTreeMap<PackageName, Version>,
    target: &PackageName,
    mode: PathMode,
    limit: usize,
) -> WhyDep;
```

### A2 — Algorithm (private fns in `crates/obs/src/lib.rs`)

Pure graph search over the lockfile, named so an auditor can trace 1:1:

1. **Index** (`fn index(lockfile) -> Adjacency`): build `node (name,version) → &BTreeMap<PackageName,Version>` (its outgoing edges) from `lockfile.iter()`. O(entries); BTreeMap iteration is sorted ⇒ deterministic traversal order.
2. **Target nodes** (`fn target_versions(...)`): collect every `(target, v)` that is (a) a `LockEntry` of name `target` (→ `integrity = Some`), or (b) referenced by some edge but has no entry (→ `integrity = None`, incomplete-lockfile case), or (c) a root of name `target`. Sort ascending by `v`, dedup. `found = !target_versions.is_empty()`.
3. **Paths to each target node** (`fn paths_to(adj, roots, target_node, mode, limit)`):
   - `PathMode::All` → DFS from each root, carrying the current path as the visited set; a neighbor already on the current path is **skipped** (simple-path constraint ⇒ cycles terminate, no infinite loop, no panic). On reaching `target_node`, record the path; stop the whole enumeration once `limit` paths are recorded and set `truncated`.
   - `PathMode::Shortest` → BFS over the same edges from the root set; the first time `target_node` is dequeued, reconstruct the one shortest path; ties broken by canonical `(name,version)` order so the choice is deterministic.
   - A root whose identity **equals** `target_node` yields the trivial path `[target_node]` and marks `direct = true`.
   - A dangling edge (neighbor with no entry) is followed only as far as that neighbor: it can be a path *endpoint* (when it is the target) but expands no further (it has no `dependencies`).
4. **Canonical order**: the returned `paths` are sorted by their node sequence (lexicographic over `(name, version)` tuples) and de-duplicated, so identical inputs always render identical bytes (`determinism` gate).

### A3 — CLI surface (`crates/cli/src/cli.rs`, fenced `// === OBS-001 ===`)

`WhyDepArgs` already exists (DIST-001 stub: `pub pkg: String`). OBS-001 flips the stub to a real dispatch arm and adds three flags:

```rust
#[derive(Debug, Args)]
pub struct WhyDepArgs {
    /// Package to explain (bare name or `@scope/name`).
    pub pkg: String,
    // === OBS-001 ===
    /// Show one shortest chain per version instead of every chain.
    #[arg(long)]
    pub shortest: bool,
    /// Emit machine-readable JSON (the serialized `WhyDep`) instead of prose.
    #[arg(long)]
    pub json: bool,
    /// Max chains to enumerate per version before reporting truncation.
    #[arg(long, default_value_t = meow_obs::DEFAULT_PATH_LIMIT)]
    pub limit: usize,
    // === /OBS-001 ===
}
```

`fn cmd_why_dep(args: &WhyDepArgs) -> ExitCode` (binary edge; owns the *only* ambient read — cwd — like `cmd_run`, keeping `meow-obs` host-pure, I-6/P16):

1. `root = find_project_root(&cwd)` then `lockfile = load_lockfile(&root)` (reuse the LOAD-001 helpers; `Lockfile::read` is strict + integrity-aware, I-7). On `LockError` → honest stderr line, exit `1`, **no panic**.
2. `config = meow_config::MeowConfig::load(&root)` (CFG-001) → the declared direct deps `config.dependencies: BTreeMap<PackageName, VersionReq>` (the field PKG-002 adds; the single declared-deps source). On `ConfigError` → honest stderr, exit `1`.
3. `roots = lockfile.resolve_roots(&config.dependencies)` — PKG-002's pure helper (`Lockfile::resolve_roots(&self, &BTreeMap<PackageName,VersionReq>) -> Result<BTreeMap<PackageName,Version>, RootResolveError>`; max lockfile version satisfying each range). On `RootResolveError::Unsatisfied { name, range }` → honest stderr, exit `1`.
4. `mode = if args.shortest { Shortest } else { All }`; `report = meow_obs::why_dep(&lockfile, &roots, &PackageName::new(&args.pkg), mode, args.limit)`.
5. Render (A4); exit `0` if `report.found`, else `1`.

### A4 — Output shape (behaviors / the acceptance bar)

**Human (default), stdout.** Found, multi-version example:

```
lodash is in the dependency tree — 2 version(s).
(each chain starts at a project direct dependency)

lodash@4.17.21  integrity sha256-K9lP…
  express@4.18.2 → body-parser@1.20.1 → lodash@4.17.21
  express@4.18.2 → lodash@4.17.21

lodash@3.10.1  integrity sha256-7Hb…
  legacy-thing@1.0.0 → lodash@3.10.1
```

- A version that is itself a direct dep prints `(direct dependency)` and the single-node chain `lodash@4.17.21`.
- A referenced-but-missing version prints `integrity (none — referenced but not in lockfile)`.
- When a version is truncated: a trailing `… showing first 256 of more chains (raise with --limit)` line.

**Not found**, stderr, exit `1` (honest miss — a legitimate negative, distinct from a crash):

```
meow: `left-pad` is not in the dependency tree (no path from any direct dependency in meow.lock.jsonl)
```

**JSON** (`--json`), stdout: `serde_json::to_string_pretty(&report)` — `{ "target", "found", "versions": [ { "node": {"name","version"}, "integrity": "sha256-…"|null, "direct", "truncated", "paths": [ {"nodes":[{"name","version"}, …]} ] } ] }`. Exit follows `found` (0/1) so `--json` stays scriptable.

Behaviors proven:
- **Multi-level**: root → A → B → target resolves to the chain `A@v → B@v → target@v`.
- **Multiple paths (diamond)**: target pulled by two owners ⇒ `All` reports both chains; `--shortest` reports the single shortest.
- **Multi-version**: `target@1` and `target@2` reachable via different roots ⇒ both grouped, each with its own integrity (LOAD-003's multi-version is inherent in `(name,version)` keying).
- **Cycle**: a cycle on the path to the target terminates with the finite set of simple paths — no infinite loop, no panic, no duplicate-node chain.
- **Not found**: name absent from entries, edges, and roots ⇒ `found = false`, exit `1`, honest message.
- **Malformed / empty lockfile**: malformed bytes ⇒ `LockError` at load → honest error, exit `1`, no panic; empty lockfile + empty roots ⇒ not found.

## Non-goals

- **`why-slow` / `why-large` / `trace` / `profile` / `doctor`** — separate OBS specs (P6: `OBS-002`/`OBS-003`; `doctor` partially CFG-002). OBS-001 ships *only* `why-dep`.
- **Capabilities, runtime cost, bundle cost** for the package (CANON §17 lists them for `why-dep`) — **deferred to P6** (capabilities need the I-8 model; cost needs the load/parse timeline). OBS-001 reports **only** what the lockfile proves: version + integrity hash. Claiming more would violate I-11; the output says nothing about them.
- **Workspace attribution** ("which *workspace* introduced it") — needs the workspace graph (`WS-001`, P4). At P2 the project is single-root; chains start at its direct deps.
- **Resolution / install / network** — `why-dep` never resolves a specifier, never fetches, never writes. It reads an already-populated lockfile (PKG-002 produces it). No `Resolver`, no `Cache` blob reads.
- **Reverse-tree / collapsed-DAG rendering** (`cargo tree --invert` style) — OBS-001 prints flat chains as specified; a shared-subpath tree view is a later ergonomic.
- **Reporting which *file* in a package imports the dep** — that is module-graph (GRAPH/LOAD) territory, not lockfile territory.

## Interface

- **New crate** `crates/obs` (`meow-obs`), library only. Public surface: `why_dep`, `WhyDep`, `TargetVersion`, `DepPath`, `DepNode`, `PathMode`, `DEFAULT_PATH_LIMIT`. No CLI of its own; no host access; no `unsafe`.
- **Consumes (does not redefine):** `meow_pkg::{Lockfile, LockEntry, PackageName, Version, ContentHash}` (PKG-001). For the CLI path only: `meow_config::MeowConfig::load` + `MeowConfig.dependencies` (CFG-001 + the PKG-002 field) and `meow_pkg::Lockfile::resolve_roots` + `meow_pkg::RootResolveError` (PKG-002).
- **CLI:** `meow why-dep <name> [--shortest] [--json] [--limit <N>]`. Exit codes: `0` found, `1` not-found (honest miss) **or** operational error (malformed lockfile / config error / unsatisfied root) — disambiguated by stream (found/miss on the query's terms; errors to stderr) and message. (`EXIT_UNIMPLEMENTED = 3` is no longer returned for `why-dep`.)
- **New external deps:** none. `meow-obs` uses `meow-pkg` (path) + `serde`/`serde_json` (already in `[workspace.dependencies]` under the LOAD-003 fence). The CLI gains a path dep on `meow-obs`. Footprint-neutral (I-10).

## Tests required

`crates/obs/tests/why_dep.rs` (integration, synthetic in-memory lockfiles built with `Lockfile::parse`) + unit tests in `lib.rs`; CLI tests in `crates/cli/tests/cli.rs`. Proves **I-11** [`honesty`] and **I-7**/**I-1** (reads the integrity-checked lockfile graph, no re-resolution). GATES: **`honesty`** (not-found + advisory boundary), **`determinism`** (byte-stable output), **`lockfile-integrity`** (consumes PKG-001's checked read; malformed ⇒ typed error, never panic — secondary). `resolver-parity` is **N/A** (no resolution happens; stated honestly). `footprint`: no new external dep (note in the footprint log).

Library (the pure core — PKG-001 only):
- **Multi-level path**: `app → a@1 → b@1 → target@1`; assert the single chain `a@1 → b@1 → target@1`.
- **All-paths (diamond)**: two owners reach `target@1`; `All` ⇒ both chains (canonical order); `Shortest` ⇒ the one shortest; assert the fork's two behaviors.
- **Multi-version**: `target@1` (via root `a`) and `target@2` (via root `b`) both present ⇒ two `TargetVersion`s, ascending, each with its own `integrity`.
- **Cycle (no panic, terminates)**: `a@1 → b@1 → a@1` plus `b@1 → target@1`; assert the finite simple-path set, every chain node-unique, and the call returns (a deliberate `#[test]` that would hang on a naive recursion).
- **Honest not-found**: `target` absent everywhere ⇒ `found == false`, `versions` empty.
- **Empty lockfile + empty roots** ⇒ not found, no panic (robustness).
- **Dangling edge**: an edge names `target@9` with no entry ⇒ `TargetVersion { integrity: None, … }`, the path ends at it, no panic.
- **Direct dependency**: `target` is a root ⇒ `direct == true`, chain `[target@v]`.
- **Determinism**: build the same logical lockfile via two different insertion orders ⇒ identical `WhyDep` and identical `serde_json` bytes; path order is canonical (property-style over shuffled inputs).
- **Truncation/limit**: a fan-out exceeding `limit` ⇒ `truncated == true`, exactly `limit` chains, and the kept subset is the deterministic canonical prefix.

CLI (integration, real binary via `assert_cmd`):
- **Real why-dep**: write a temp project (`meow.config.json` with `dependencies` + a `meow.lock.jsonl`); `meow why-dep <name>` exits `0` and stdout contains the expected chain.
- **Not found**: exits `1`, stderr contains the honest "not in the dependency tree" message.
- **Malformed lockfile**: a non-canonical/garbage `meow.lock.jsonl` ⇒ exits `1`, honest `LockError` message on stderr, **no panic** (the `lockfile-integrity` robustness case at the CLI edge).
- **`--json`**: output parses as JSON and carries `found` + `versions[].node`.
- **`--shortest`**: a diamond project ⇒ exactly one chain printed.
- **Stub table updated**: `every_subcommand_stub_is_honest` no longer lists `why-dep` and asserts `CASES.len() == 14`.

Floor: `cargo test`/`clippy`/`fmt` + `principles-check.sh` (frontmatter refs, fence balance, P16 no-ambient-reads in `meow-obs`).

## Operator notes

Integration points (named):
- **PKG-001:** consumes `Lockfile::{read, parse, iter, get}`, `LockEntry.{name, version, integrity, dependencies}`, `PackageName`, `Version`, `ContentHash::to_sri` — read-only.
- **PKG-002 (coordinated over `irc`, peer `PKG002`):** `MeowConfig.dependencies: BTreeMap<PackageName, VersionReq>` (the single declared-direct-deps source) + `Lockfile::resolve_roots(&self, &BTreeMap<PackageName, VersionReq>) -> Result<BTreeMap<PackageName, Version>, RootResolveError>` (max-satisfying pin; lives in `crates/pkg/src/lockfile.rs`, re-exported). `cmd_run` will call the same helper to build `Resolver::new`'s `root_deps`, so `why-dep` and the runtime agree on roots by construction (I-1).
- **CFG-001:** `meow_config::MeowConfig::load(&Path)`.
- **LOAD-001:** reuses `find_project_root` + `load_lockfile` in `crates/cli/src/cli.rs`.

Forks (logged to `harness/decisions.json` as `assumption` records — surfaced here too, not buried):

1. **All-paths vs shortest (the called-out fork).** Default = **all simple paths** (`PathMode::All`). Rationale: a package's full "why" is *every* owner that pulls it in; showing only the shortest hides co-owners (matches `npm why`, `cargo tree -i`). `--shortest` is the opt-in for one representative chain. Pathological blow-up is bounded by `--limit` (default `256`) with an honest "truncated" note (I-11), since simple-path enumeration is worst-case exponential. Reversible (internal default + a flag). → `decisions.json` id `A-OBS1-PATHS`, confidence **medium**.

2. **Root-deps source ⇒ `depends_on` is wider than the assignment's `[PKG-001]`.** The assignment said `depends_on: [PKG-001]`; per `PKG002`'s authoritative answer, the lockfile **cannot** distinguish direct from transitive deps (an in-degree-zero heuristic is *wrong*: transitive-only packages can be in-degree-zero, and a direct dep can have in-edges from transitives). The correct source is `MeowConfig.dependencies` pinned via `Lockfile::resolve_roots` (PKG-002). So the **pure library** is `[PKG-001]`-only (as intended), but the **full CLI** honestly needs `[PKG-001, PKG-002, CFG-001]`, which is what the frontmatter declares. → `decisions.json` id `A-OBS1-ROOTS`, confidence **high** (corroborated by PKG002), reversible.

Honest coverage (report): COVERED — multi-level/all/shortest paths, multi-version grouping, cycle-safety, dangling-edge tolerance, direct-dep detection, honest not-found, deterministic + bounded output, version + integrity hash. NOT covered (by design, deferred): capabilities, runtime/bundle cost (P6), workspace attribution (P4), file-level importer (GRAPH/LOAD), reverse-tree rendering. The command advertises none of the deferred facts — what it prints is exactly what the lockfile proves.
